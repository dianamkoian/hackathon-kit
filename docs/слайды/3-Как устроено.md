# Слайд 3. Как устроено

## На слайде

Схема в четыре шага, по нарастанию цены:

```
текст / голос / скриншот
        ↓
   ДЕТЕКТОРЫ          без модели вообще: ссылки, карты, просьбы кода,
        ↓             подмена букв. Бесплатно и мгновенно
   ДЕШЁВАЯ МОДЕЛЬ     разбор простых случаев
        ↓
   СИЛЬНАЯ МОДЕЛЬ     только когда дешёвая не справилась
        ↓
   ПРОВЕРКА ОТВЕТА    цитаты сверяются с текстом механически
        ↓
   ОТВЕТ или ОТКАЗ
```

## Что сказать (60 секунд)

«Самый дешёвый уровень нашего каскада — это **отсутствие модели**.

Звучит странно на ИИ-хакатоне, но вот в чём дело: часть приёмов не нужно
угадывать, их видно. Ссылка в тексте либо есть, либо нет. Просьба продиктовать
код либо есть, либо нет. На это не нужна нейросеть, нужен детектор — и он
бесплатен, мгновенен и не галлюцинирует по построению.

Модель подключается там, где нужно понимание. А проверяет ответ снова код:
каждая цитата сверяется с исходным текстом. Модель не может сослаться на то,
чего в сообщении нет.»

## Если спросят про ИИ-пайплайн (критерий «использование ИИ»)

Три модели, каждая на своём месте: распознавание речи локально, зрение для
скриншотов, языковая модель для разбора. Плюс эмбеддинги для второго режима.
Все локальные — ничего не уходит с устройства.
