# Слайд 2б. Что умеет Verka

В колоде (`web/slides.html`) — сразу после «Улики вместо приговора».

## На слайде

1. **Разбирает сообщение** — оценка, приёмы с цитатами прямо в тексте, одно
   действие на полминуты.
2. **Честно говорит «не уверены»** — вместо вердикта проверка.
3. **Отвечает без нейросети, когда видно и так** — ссылка, номер карты,
   просьба кода, подмена букв: ответ за секунду.
4. **Сравнивает с одной моделью** — кнопкой на экране.
5. **Читает скриншоты и голосовые** — скриншот в браузере, голос на Маке.
6. **Помнит: «вам прислали не первому».**
7. **Не верит новости без источника** — кнопки поиска.
8. **Учит распознавать обман** — тренировка на 10 сообщениях.

Тарифы: lite — бесплатно, 5 проверок в день; pro — 199 ₽/мес, семья до 5
человек; enterprise — API с документацией `/docs`.

## Что сказать (30 секунд)

«Это не только разбор. Verka читает скриншоты и голосовые, помнит, что такое
сообщение уже присылали другим, не верит новостям без источника и учит
распознавать обман на тренировке. А когда не уверена — так и говорит и даёт
проверку.»

## Чего не обещать

- «Голос не уходит с устройства» — только на Маке. На рабочей ссылке (Windows)
  голос распознаёт браузер: Chrome и Edge отправляют звук в Google, Safari — в Apple.
- Для скриншотов нужен интернет: библиотека грузится с CDN.
- «Сообщить близкому одной кнопкой» есть только в описании тарифа — на экране
  этого нет, не показывать.
