# docs/

Сюда кладётся запись демо — `demo.gif`, на которую ссылается главный README.

Как записать на macOS:

1. `Cmd+Shift+5` → выбрать область → записать 30–60 секунд. Покажите один
   полный сценарий: ввод, трассировку, и обязательно случай, когда система
   отказывается отвечать. Отказ — то, чего нет у других команд.
2. `bash scripts/record-demo.sh ~/Desktop/запись.mov docs/demo.gif`
3. Раскомментировать строку с картинкой в README.

Первая запись делается на втором часу хакатона и потом обновляется. Она
уродливая и на одном кейсе — так и надо: репозиторий должен выглядеть
работающим до того, как проект готов.
