# Страница о ценности «Второго мнения»

Подготовлено по просьбе Сони 25.10.2026. Это отдельный материал для включения в презентацию Карины; существующие слайды не изменены.

- `second-opinion-value.png` — 3200 × 1800, вставить изображением на весь слайд 16:9.
- `second-opinion-value.pdf` — одна страница 16:9 для просмотра и показа.
- `second-opinion-value.svg` — редактируемые тексты и векторные элементы. Шрифт Arial.
- `render.py` — исходник сборки на Pillow; использует установленные шрифты macOS. Генерация не нужна для показа готовых файлов.

Пример сообщения — иллюстрация сценария, не настоящий результат прогона. На странице нет обещания определить подлинность или гарантии точности.

Текст выступления, примерно 25 секунд:

«Подозрительные сообщения часто требуют действовать прямо сейчас: перевести деньги, назвать код, перейти по ссылке. Наш продукт помогает сделать паузу. Человек видит конкретные фразы, которые вызвали сомнение, и получает следующий шаг — например, позвонить на прежний номер. Если проверка ответа не пройдена, система отказывается от вывода. Ценность — понятное действие даже тогда, когда уверенного ответа нет».
