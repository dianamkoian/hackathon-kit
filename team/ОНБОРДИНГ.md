# Что сделать до начала — 15 минут

Прочитай один раз. Это всё, что нужно, чтобы начать не с нуля.

## Шаги

1. **Прими приглашение в репозиторий.** Открой
   https://github.com/dianamkoian/hackathon-kit — там будет кнопка. Без этого
   клонирование упадёт с «repository not found», и это выглядит как
   неправильная ссылка, хотя дело в доступе.

2. **Клонируй по HTTPS, не по SSH:**
   ```bash
   git clone https://github.com/dianamkoian/hackathon-kit.git
   ```

3. **Проверь окружение** — одна команда, скажет что есть и чего не хватает:

   на Mac и Linux:
   ```bash
   python3 scripts/doctor.py --setup
   python3 -m evals.run
   ```
   на Windows (команды `python3` там обычно нет, пишите `python`):
   ```bash
   python scripts\doctor.py --setup
   python -m evals.run
   ```
   Нужен Python 3.10 или новее. Должна напечататься таблица с метриками.
   Должна напечататься таблица с метриками. Ставить ничего не надо: работает
   на заглушках, без ключей и без интернета.

4. **Поставь зависимости дома, а не на площадке:**
   ```bash
   pip install -r requirements.txt
   ```
   На площадке интернет может не дать это сделать, и тогда не заработает
   демо-страница.

5. **Проверь, чьим именем подписываются твои коммиты:**
   ```bash
   git config user.email
   ```
   Должна быть твоя почта. Историю потом не переписать, а то, как команда
   делила работу, жюри оценивает отдельным критерием.

6. **Заведи свой файл статуса:** скопируй `team/статусы/_ШАБЛОН.md` в
   `team/статусы/<своё-имя>.md`, заполни, закоммить.

## Что уже готово, чтобы не делать заново

- **Ядро.** Запросы сами идут на дешёвую или дорогую модель; ответ проверяется
  до выдачи; при сомнении система отказывается отвечать вместо того, чтобы
  придумать. Папка `core/` — её не трогаем.
- **Измерение качества.** Одна команда — и видно, сколько ответов верных,
  сколько неверных, сколько стоило, как быстро. Это главный аргумент на защите.
- **Демо-страница** с видимой трассировкой: какой шаг, какая модель, что решил.
- **Распознавание речи** — если тема окажется про созвоны или голос.
- **Шесть локальных моделей** уже скачаны на ноутбуке Дианы. Локальные модели
  работают только на Mac с процессором Apple. **На Windows** доступны заглушки
  (`LLM_BACKEND=mock` — без ключа и без сети, на них работает вся проверка
  качества) и платная модель по ключу (`LLM_BACKEND=anthropic`). Для разработки
  и прогонов заглушек достаточно: на них считается вся таблица метрик.
- **План по часам** — `RUNBOOK.md`, в том числе сжатый на 4 часа.
- **Скелет защиты** — `docs/ЗАЩИТА.md`.

Под тему переписывается **один файл**: `domains/<тема>.py`.

назвать твою зону — он спросит сам.
