## Интерфейс для Дианы
```python
from core.verify import find_mechanical_signals, check_signals
signals = find_mechanical_signals(text)
# [{"kind": "link", "quote": "https://example.com", "start": 0, "end": 19,
#   "domain": "example.com"}, ...]

problems, signals = check_signals(
    data, text, {"link": "external_link", "secret_request": "code_request"},
    type_field="markers[].type", verdict_field="assessment", unsafe_verdicts=("trust",))
```
Каждая quote — точный срез text[start:end]; позиции — индексы Python-строки.

| kind | Что определяется | Ограничение |
|---|---|---|
| `card_number` | 16 цифр группами по 4 (без проверки Луна) или подряд (с Луном); маска `2202 **** 4411`, `220220******4411`; поле `masked` | «*4411» из банковских уведомлений не ловится; не подтверждает, что карта существует |
| `link` | http(s)://, www., голые домены с известной зоной (.ru, .top, .site, .net…); поле `domain`, userinfo `bank.ru@evil.top` даёт `evil.top` | Не проверяет репутацию и содержимое сайта |
| `secret_request` | Просьба назвать/продиктовать/сообщить/ввести код из СМС, пароль, CVV, ПИН — в обоих порядках слов | Отрицание в той же части фразы перед глаголом пропускается; цитированную речь не понимает |
| `phone_number` | +7/8 и 10 цифр в любой обычной записи; +код страны | Маска `8 800 ***-**-**` не ловится |
| `mixed_script` | Слова с греческими буквами внутри, с двумя и более сменами алфавита или с буквами-двойниками | Составные бренды «СберPay», «ЮMoney» пропускаются; «PDFка» может сработать — это только сигнал |
| `invalid_inn` | ИНН не из 10/12 цифр или с неверной контрольной суммой; поле `reason` | Верный ИНН не сообщается: он ничего не доказывает |

Признак сам по себе не задаёт trust/doubt/distrust; отсутствие признаков не подтверждает безопасность.

Минимальное воспроизведение:
```python
from core.structured import StructuredError, extract_json, validate
from core.verify import check_quotes, find_mechanical_signals
assert check_quotes({'q': 'выдуманная цитата'}, '', ('q',))
for text in ['{"confidence":NaN}', '{"confidence":1e999}', '{"x":1,"x":2}']:
    try:
        extract_json(text)
    except StructuredError:
        pass
    else:
        raise AssertionError(text)
assert validate(2, {'type': 'number', 'minimum': 0, 'maximum': 1})
assert not find_mechanical_signals('Никому не сообщайте код из СМС')
assert find_mechanical_signals('Пришлите код из СМС')[0]['kind'] == 'secret_request'
```

### Формулировка для слайда
«Второе мнение» делает разбор проверяемым: связывает признаки с цитатами из сообщения, механически проверяет цитаты ответа, показывает этапы проверки и предлагает одно действие из каталога. Если проверка ответа не пройдена, система явно отказывается от уверенного вывода.

Это акцент прототипа, а не доказанное отсутствие аналогичных механизмов у всех конкурентов. На демо можно показать отклонение выдуманной цитаты в trace и случай отказа.

### Что не обещаем на защите
- «У конкурентов нет рекомендаций, объяснений или отказа» — противоречит описаниям Norton/Bitdefender.
- «Мы доказываем подлинность» — совпадение цитаты доказывает её наличие в тексте, а не истинность содержания и не личность отправителя.
- «Мы точнее/дешевле конкурентов» — сравнительного эксперимента нет; eval сравнивает собственные baseline и каскад.
- «Локальная модель бесплатна» — нет оплаты API за локальный вызов, но вычислительные затраты остаются.
