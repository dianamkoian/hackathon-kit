# Соня — механические проверки и конкуренты

Обновлено: 25.10.2026, после реализации и проверки кода.

## Сейчас делаю
Первая реализация закончена. Передаю интерфейс функций и материал о конкурентах. Новые признаки готовы для подключения владельцем доменной логики.

## Готово
- В `core/verify.py` устранён обход проверки цитат при пустом источнике.
- Цитаты верификатора из `found_in_source` и `missing_from_answer` тоже сверяются с исходным текстом. Результат виден в trace как `verify_ground`.
- Полнота ответа проверяется по объединению найденных и объявленных пропущенными фрагментов: пустой `missing_from_answer` больше не скрывает перечисленный верификатором пропуск.
- Короткая цитата ответа больше не считается покрывающей длинный фрагмент с дополнительным действием. Широкая цитата ответа по-прежнему покрывает узкую цитату верификатора.
- В `core/structured.py` значения `NaN`/`Infinity`, переполнение `1e999` и повторяющиеся JSON-ключи вызывают повторяемую ошибку `StructuredError`. Добавлены `minimum`/`maximum`; confidence проверяется по диапазону 0–1.
- Добавлена `find_mechanical_signals(text)` без сети и LLM.

## Интерфейс для Дианы
```python
from core.verify import find_mechanical_signals
signals = find_mechanical_signals(text)
# [{"kind": "url", "quote": "https://example.com", "start": 0, "end": 19}, ...]
```
Каждая quote — точный срез text[start:end]; позиции — индексы Python-строки.

| kind | Что определяется | Ограничение |
|---|---|---|
| `url` | Адреса с http://, https:// или www. | Не проверяет репутацию, содержимое сайта и маскированные ссылки |
| `sms_code_request` | Явная русская просьба прислать/сообщить/назвать код из СМС | Исключает простое «не сообщайте»; не понимает сложный контекст и цитированную речь |
| `card_number_candidate` | 13–19 цифр с контрольной суммой Луна и упоминанием карты перед номером | Не подтверждает существование карты, её владельца или мошенничество |

Признак сам по себе не задаёт trust/doubt/distrust; отсутствие признаков не подтверждает безопасность. Функция пока не подключена к маршрутизатору/промпту: это зона Дианы (`domains/authenticity.py`, `core/pipeline.py`). Исправления существующих проверок цитат и структуры уже действуют при обычном запуске.

- Проверки выполнялись в отдельной копии; пользовательские изменения в evals/report.md не включены в нашу работу.

Минимальное воспроизведение регрессий:
```python
from core.structured import StructuredError, extract_json, validate
from core.verify import check_quotes, find_mechanical_signals
assert check_quotes({'q': 'выдуманная цитата'}, '', ('q',))
for text in ['{"confidence":NaN}', '{"confidence":1e999}', '{"x":1,"x":2}']:
    try:
        extract_json(text)
    except StructuredError:
        pass
    else:
        raise AssertionError(text)
assert validate(2, {'type': 'number', 'minimum': 0, 'maximum': 1})
assert not find_mechanical_signals('Никому не сообщайте код из СМС')
assert find_mechanical_signals('Пришлите код из СМС')[0]['kind'] == 'sms_code_request'
```
Строгое покрытие цитат может увеличить отказы при слишком широком цитировании реальной моделью. Нужен прогон Альбины на реальных моделях; рост точности или гарантию доли ошибок по этим тестам не заявляем.

## Конкуренты — материал для Карины и Саши
Проверено 25.10.2026 по официальным описаниям. Это документальное сравнение, не сравнительный запуск. Отсутствие функции в описании не доказывает её отсутствия в продукте.

| Решение | Вход и заявленный результат | Вывод для позиционирования |
|---|---|---|
| [Norton Genie](https://support.norton.com/sp/en/us/home/current/solutions/v20230717145233467) | Тексты и скриншоты сообщений, писем и сайтов; оценка, объяснение и следующие шаги. FAQ предусматривает случаи, когда определить мошенничество не удалось. | Нельзя говорить, что конкуренты дают только вердикт или не признают неопределённость. |
| [Bitdefender Scamio](https://www.bitdefender.com/consumer/support/answer/97320/) | Сообщения, ссылки, QR-коды, изображения/скриншоты; оценка угрозы и рекомендации. | Следующее действие и объяснение сами по себе не уникальны. |
| [ScamShield](https://www.scamshield.gov.sg/check-for-scams/how-to-check-for-scams-on-scamshield-app/) | Номера, сообщения, ссылки, скриншоты; сопоставление с проверенными источниками, известными схемами и сообщениями сообщества. | У конкурента есть внешние сигналы доверия; наш прототип в основном анализирует предоставленный текст. |

### Формулировка для слайда
«Второе мнение» делает разбор проверяемым: связывает признаки с цитатами из сообщения, механически проверяет цитаты ответа и верификатора, показывает этапы проверки и предлагает одно действие из каталога. Если проверка ответа не пройдена, система явно отказывается от уверенного вывода.

Это акцент прототипа, а не доказанное отсутствие аналогичных механизмов у всех конкурентов. На демо можно показать отклонение выдуманной цитаты в trace и случай отказа.

### Что не обещаем на защите
- «У конкурентов нет рекомендаций, объяснений или отказа» — противоречит описаниям Norton/Bitdefender.
- «Мы доказываем подлинность» — совпадение цитаты доказывает её наличие в тексте, а не истинность содержания и не личность отправителя.
- «Мы точнее/дешевле конкурентов» — сравнительного эксперимента нет; eval сравнивает собственные baseline и каскад.
- «Локальная модель бесплатна» — нет оплаты API за локальный вызов, но вычислительные затраты остаются.
