## Зачем
решение team/решения/007: «Второе мнение» → Verka, тарифы lite / pro / enterprise (цены прежние). Экран уже переименован, на демо показывается Verka pro. Если README и слайды останутся со старым названием, жюри увидит два разных продукта. Как писать — в решении 007; знак — web/logo/logo.svg. В web/slides.html (колода Дианы, /slides) старое название в заголовке и титуле — согласуйте с Дианой, кто правит

## Как понять, что готово
README, слайды и web/slides.html называют продукт Verka; тарифы — lite / pro / enterprise; в видео на экране «Verka pro»

## Ответ
В работе.

- README и слайды в `docs/слайды/`: продукт называется Verka. Тарифы в них не
  упоминаются, переименовывать нечего.
- `web/slides.html`: кто правит название — согласую с Дианой.
- Видео: кадр с отказом записываю, когда экран готов, — на нём будет Verka pro.
