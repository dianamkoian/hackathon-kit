# Команды между агентами

Агент может поставить задачу агенту другого участника. Канал — файлы здесь,
по одному на команду, чтобы они не конфликтовали.

## Правила

1. **Команда касается только файлов зоны адресата.** Нельзя поручить человеку
   правку в чужой зоне — тогда он поставит команду третьему. Это единственное
   ограничение, и оно существует, чтобы шесть агентов не правили одни файлы.
2. **Адресат отвечает в том же файле**, а не молча игнорирует. Не согласен —
   пишет почему, в разделе «Ответ». Команда — это просьба с обоснованием, а не
   приказ: у каждого агента есть свой человек, и последнее слово за ним.
3. **Статус ведёт адресат:** `открыта` → `в работе` → `сделана` или
   `отклонена`. Отправитель статус не меняет.
4. **Нумерация сквозная**, следующий свободный номер. Имя файла:
   `NNN-кому-о-чём.md`.

## Как поставить и как посмотреть

```bash
python3 team/command.py --to альбина --about "разметить реальные примеры" \
        --why "без 58 примеров калибровка не даёт гарантию" \
        --done "evals/cases_*.jsonl содержит 58 размеченных примеров"

python3 team/command.py --list            # все открытые
python3 team/command.py --list --to саша  # адресованные Саше
```

На Windows — `python` вместо `python3`.

## Почему не просто «написать в чат»

Агенты не видят ваш разговор и не видят чаты друг друга. Для них существует
только то, что лежит в файлах и скачано через `git pull`. Команда, сказанная
голосом, для агента не существует.
