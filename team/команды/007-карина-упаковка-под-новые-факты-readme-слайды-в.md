**От:** Диана Мкоян
**Кому:** карина (зона: README.md, docs/)
**Статус:** сделана

## Что сделать
Три факта появились сегодня, их обязательно надо отразить — они сильнее всего, что было раньше.

1. ГЛАВНОЕ: продукт отвечает БЕЗ нейросети. Детекторы видят ссылку, номер карты и просьбу кода прямо в тексте, без вызова модели — бесплатно, мгновенно и без галлюцинаций: цитата берётся из текста по позиции, а не пишется моделью. На защите это звучит так: «самый дешёвый уровень нашего каскада — это отсутствие модели». Проверено: «продиктуйте код из СМС + ссылка» разбирается в ноль вызовов.
2. Данные частично настоящие: 35 размеченных примеров, 5 — настоящие письма участников. На вопрос «откуда данные» отвечаем числом. Строка про это в README уже есть, не потеряй её.
3. Каждая проверка сохраняется: «вы не первый, кому это прислали», и корпус растёт сам — включая то, что введёт жюри на защите.

Что сделать:
1. README: заменить ⟨НАЗВАНИЕ ПРОЕКТА⟩ и описание задачи. Таблицу чисел не трогать, она сверяется автоматически перед пушем.
2. Слайды: каркас в docs/слайды/, что на каждом — в docs/ЗАЩИТА.md. Материал для слайда «чем мы отличаемся» готов в docs/КОНКУРЕНТЫ.md, со ссылками на механизм Community Notes.
3. Видео 1-2 минуты. Обязательные кадры: (а) система ОТКАЗЫВАЕТСЯ отвечать и даёт проверку — этого нет ни у кого; (б) разбор без модели; (в) детектор поймал подмену русских букв греческими в настоящем письме — слова с подменёнными буквами. Человек такое не заметит, а код видит. Запись: bash scripts/record-demo.sh ~/Desktop/запись.mov docs/demo.gif

за последний час продукт изменился принципиально, и в README этого нет. До заморозки час

## Ответ
Сделано. README переписан под новые факты: без нейросети, детекторы, голос и
скриншоты, повторы, публичная ссылка, числа набора 120 с источником корпуса
(`345a879`, `d256e32`, `5ec2772`). Слайды и колода: слайд 4 с числами, «Что
