## Что сделать
Пока письма Сони были среди примеров на экране, их могли прогнать через Verka, и тогда их тексты сохранились в базе проверок `data/checks.db` (`core/store.py`) на машине с рабочей ссылкой. Соня просит удалить их оттуда.

Самих текстов здесь нет: только их отпечатки, те же, что `core/store.py` считает в поле `text_hash`. По отпечатку текст не восстановить.

1. Удалить строки по отпечаткам (сервер можно не останавливать):
```bash
python3 - <<'PY'
import sqlite3
db = sqlite3.connect("data/checks.db")
hashes = ('9201bebacc003508fb54a1d215f9933c', '8e1b76331ae705a5778f1db7a99799d6', 'd722ea26ef5fdec126a602c78ba2c65b', 'a75b74184852182cf2340be8252f1ac9', '543530752650d9df15b5f82e482f811f', '9cb8a464c97fc206bb7b6e3b9265f8bf', '7780d5bddd4d53fbc77060841c6b6aa1', '8c156bcd1d1bb194d8141d722581b728', '633d5812b5c94034853ad725e1ae5e43', '9db3a5c2ccfdb344ce4ee4d3612e79cb')
n = db.execute(f"DELETE FROM checks WHERE text_hash IN ({','.join('?'*len(hashes))})", hashes).rowcount
db.commit(); db.execute("VACUUM"); print("удалено строк:", n)
PY
```
На Windows вместо `python3` пиши `python`. Если терминал не bash, сохрани строки между `PY` в файл `purge.py` и запусти `python purge.py` из корня репозитория.

2. Если ты делал выгрузку базы (`export_jsonl`) в файл, удали из него те же сообщения или весь файл.
3. В ответе напиши только число удалённых строк, без текстов.
