2. Перезапустить **только** `uvicorn api.server:app --port 8000`: он запущен без `--reload`, поэтому новые правила не подхватит сам. **cloudflared не трогать**, тогда адрес https://background-estates-move-aid.trycloudflare.com останется прежним.

## Зачем
В `ca040ee` новости и слухи: проверка C20 с поиском, приёмы «перешлите всем» и «власти скрывают», и спокойная новость без источника больше не получает «доверять». Ещё там правка в твоём `api/server.py`: три вызова `present(...)` теперь передают `req.text`, по строке на вызов. Это нужно для ссылок поиска. Без перезапуска сервера на показе останется старое поведение.

## Как понять, что готово
`/healthz` отвечает, адрес ссылки тот же, проверка из пункта 3 даёт C20.

## Ответ
**Перезапуск сделан** (Дима, 25.10 ~15:45). `git pull` до `385b613`, смоук
проходит, перезапущен только uvicorn (`LLM_BACKEND=ollama`,
`MODEL_DEADLINE=30`). cloudflared не трогал — адрес прежний,
https://background-estates-move-aid.trycloudflare.com, `/healthz` отвечает.

**Пункт 3 не проходит, и это не деплой.** Текст про метро в Казани через
публичную ссылку:

- живая модель (`qwen2.5:7b`): `status=ok`, **`trust`, `C00`**, `search` нет — 14 с;
- локально на mock: `mechanical`, `doubt`, `C00`, `search` нет.

Почему: для этого текста C20 держится **только на инструкции в промпте**
(`domains/authenticity.py:99-101`: «новость без источника — не trust, а doubt
и C20»). Детекторы дают C20 лишь при `spread_call` / `suppression`
(`authenticity.py:381`), а в тексте про Казань этих слов нет. 7B инструкцию
проигнорировала. На Маке Дианы (mlx, тоже 7B), скорее всего, так же.

То есть на рабочей ссылке спокойная новость без источника **по-прежнему
может получить «доверять»** — по решению 008 это «экран пишет неправду».
Чинить — в `domains/` (не моя зона): например, механическое правило после
модели, а не только строка в промпте. Решать тебе / Диане.
