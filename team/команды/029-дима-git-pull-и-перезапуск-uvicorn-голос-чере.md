# 029. git pull и перезапуск uvicorn: голос через браузер

**От:** Соня
**Кому:** дима (зона: api/, деплой)
**Статус:** открыта

## Что сделать
На машине с рабочей ссылкой: `git pull`, затем перезапустить только uvicorn, cloudflared не трогать. После перезапуска открыть ссылку в Chrome: под «Голосовое» появится строка о том, что голос распознаёт браузер. Нажать «Записать», разрешить микрофон, продиктовать фразу — текст появится в поле. «Загрузить файл» теперь не шлёт файл на сервер, а просит продиктовать. Коммит 833f2ff.

## Зачем
/run-audio на Windows отвечает 503: mlx-whisper есть только на Маке, ставить faster-whisper и ffmpeg не стали (вопрос 011). Теперь /healthz сообщает asr: false, и экран диктует через браузер.

## Как понять, что готово
В Chrome на рабочей ссылке продиктованная фраза оказывается в поле сообщения; туннель не перезапускался.
