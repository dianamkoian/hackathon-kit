# Правила для ИИ-агентов в этом репозитории

Полные правила — в `CLAUDE.md`. **Прочитай его сейчас**, он короткий. Этот файл
существует для инструментов, которые читают `AGENTS.md`, но не `CLAUDE.md`.

Три правила, которые нельзя нарушать даже не читая остального:

1. **Правь только файлы зоны своего человека.** Распределение —
   `team/решения/003-роли-и-зоны-файлов.md`. Спроси зону у человека в первом
   же сообщении, если он её не назвал. Задача требует чужих файлов — скажи
   об этом, не делай.
2. **Не трогай `core/`, если это не твоя зона, и не добавляй зависимости.**
   Ядро написано и проверено замерами. Новый пакет ломает окружение у
   остальных пятерых.
3. **Числа в README и на слайдах берутся только из `python3 -m evals.run`.**
   Придуманное число — это провал на защите в тот момент, когда жюри попросит
   воспроизвести.

Состояние команды и договорённости — в `team/`. Своему человеку пиши статус в
`team/статусы/<его-имя>.md`, чужие только читай. Перед чтением `git pull`,
после записи `git push`: общего контекста между агентами нет, и решение,
которого нет в файле, для остальных не существует.
